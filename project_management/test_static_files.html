Test 3: Django Static Files

To test Django static files serving:

  1. Run: python manage.py collectstatic
  2. Check if file exists: core/static/core/css/workflows_priorities.css
  3. Try accessing directly: http://localhost:8000/static/core/css/workflows_priorities.css

Quick Fixes

  1. Clear Cache: Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Collect Static: Run python manage.py collectstatic --noinput
  3. Restart Server: Stop and restart Django development server
  4. Check Path: Verify CSS file exists in core/static/core/css/
